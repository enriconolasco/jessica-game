# Revisão de mudanças visuais do web

Status: revisão por agente suspensa a pedido do usuário em 2026-09-25 para economizar
cota. Os critérios abaixo ficam como referência; não executar novos agentes até
nova solicitação.

A cada lote visual, executar uma revisão independente por agente crítico depois da
implementação e da verificação no navegador. Critérios, de 0 a 10:

- precisão ao pedido e à PlayerView;
- identidade visual coerente com `DIRECAO_VISUAL.md`, evitando aparência genérica;
- qualidade de acabamento: geometria, hierarquia, legibilidade e consistência;
- usabilidade e acessibilidade: teclado, foco, toque, celular e excesso de unidades.

A meta de aceitação é **mais de 8,5 em cada critério**, sem arredondar uma nota 8,5
para aprovação. O crítico deve justificar as notas com observações verificáveis.
Corrigir achados e solicitar nova avaliação; nunca solicitar que o crítico aumente
uma nota para atingir a meta. Se a revisão ficar indisponível, registrar a limitação
e não declarar o lote aprovado por esse critério.

As notas são avaliações editoriais, não uma garantia objetiva de qualidade nem prova
de autoria humana. Testes funcionais e inspeção visual continuam necessários.
